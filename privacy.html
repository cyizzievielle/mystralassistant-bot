This Privacy Policy outlines how CYZA - Mystral Assistant ("the Bot", "we", "us") collects, utilizes, stores, protects, and handles your data when you interact with our application across Discord servers.

1. Information We Collect

We only collect minimal operational data necessary to perform the Bot's services:

  • User Identifiers: Discord User ID and Username (used to maintain custom Identity Card profiles /idcard, daily pair interaction streaks /streak, and moderation logs).
  • Guild & Channel Identifiers: Discord Guild ID and Channel ID (used to store server configurations, custom autoresponders car, sticky messages, and support ticket settings).
  • User Provided Content: Custom profile entries voluntarily submitted by users (such as ID Card name, domicile, hobbies, status quote, custom autoresponse triggers, and submitted Truth/Dare questions).

2. Data We DO NOT Collect or Process

  • We do NOT store private chat message contents or chat history off-platform.
  • We do NOT collect real-life names, financial data, passwords, payment details, or IP addresses.
  • We do NOT permanently track or store presence/game activity data. Presence status is queried dynamically in real-time in memory only when server stats commands (/serverinfo) are executed.
  • We do NOT use any data to train machine learning or AI models.

3. How We Use Collected Data

All stored data is used exclusively to deliver application features:

  • Rendering 2D Canvas Cyber Identity Cards and pair interaction Flame Streak profile cards.
  • Executing automated server moderation rules, role distribution, and support ticket desk operations.
  • Maintaining guild administrator configurations and warning logs.

4. Data Security & Encryption at Rest

We take security seriously. All persistent database records are hosted on managed MongoDB Atlas cloud infrastructure:

  • Encryption at Rest: Storage volumes are fully encrypted at rest using FIPS 140-2 validated AES-256 bit encryption.
  • Encryption in Transit: All data transmitted between the bot application server and the database cluster is encrypted using TLS 1.2 / TLS 1.3 protocols.

5. User Data Deletion Rights (Right to be Forgotten)

Users have the full right to request deletion of their stored profile data and records at any time. You can request complete data removal by:

  • Opening a support ticket in #ticket-support ↗ within our server Mystral District or using /ticketpanel.
  • Sending a Direct Message to the Bot Owner @2cyi on Discord.

All data deletion requests are processed promptly within 24 hours of receipt.
